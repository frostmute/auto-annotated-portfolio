# Portfolio design context

## Audience

Hiring managers, collaborators, clients, open-source users, and technical peers looking for evidence of work across design, software, production, and operations.

## Personality

Direct, technically literate, experimental, self-taught, and grounded in real production work. No generic agency copy.

## Direction

Preserve the existing terminal/brutalist structure. Use a near-black base (`#15151F`), white text, violet (`#8B5CF6`) and cyan (`#7DD3FC`) accents, system fonts, restrained abstract imagery, and responsive layouts.

## Reference sites

- Legacy content source: https://jonathanjwagner.super.site
- Work archive: https://www.behance.net/jonathanjwagner
- Code: https://github.com/frostmute

## Accessibility

WCAG AA baseline, semantic headings, useful image alt text, visible links, keyboard-accessible native controls, and reduced-motion-safe interactions.
