## Capture, research, synthesize, file

Hermes Clipper tested a three-part local workflow: a browser extension captured source context, a secure local backend routed it to Hermes Agent, and an Obsidian plugin received structured research notes.

I designed the system around agent-assisted extraction and synthesis, token-efficient structural indexing, explicit error reporting, and a local-first trust boundary. The prototype reached an alpha release before I archived the code and carried its strongest patterns into newer import and knowledge-management systems.

**Role:** Product design, system architecture, browser-extension workflow, Obsidian integration, local backend design

**Stack:** Browser extension APIs, Hermes Agent, Obsidian API, local HTTP bridge
