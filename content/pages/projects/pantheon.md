## A small agency that ships artifacts

Pantheon coordinates research, writing, marketing, engineering, and system-wide orchestration through five persistent Hermes Agent profiles: Calliope, Clio, Eris, Prometheus, and Nyx.

I designed the system architecture, identities, role boundaries, output contracts, installation and pipeline scripts, atomic artifact storage, task logging, and the near-black mission-control dashboard. The system favors observable work over simulated status: every artifact is a file and every dashboard claim is backed by real state.

**Role:** System architecture, agent design, workflow design, visual identity, dashboard product design, automation

**Stack:** Hermes Agent, Python, SQLite, shell, HTML/CSS/JavaScript, Tailscale
